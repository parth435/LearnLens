\# LearnLens



\## AI-Powered Learning Gap Detector



LearnLens is an AI-powered educational platform that analyzes student responses to identify concept-level learning gaps, explain the evidence behind those gaps, and generate personalized study recommendations and practice questions.



\## Core Flow



Assess → Diagnose → Explain → Remediate → Reassess



\## Features



\- MCQ and theory assessment

\- AI-assisted theory answer evaluation

\- Concept-level learning gap detection

\- Evidence-based gap analysis

\- Confidence and severity indicators

\- Personalized recommendations

\- Targeted practice questions

\- Student progress tracking

\- Teacher analytics dashboard

\- Gamification and leaderboard



\## Technology



\- React + Vite + TypeScript

\- Tailwind CSS

\- FastAPI

\- Python

\- SQLite

\- AI/LLM APIs
